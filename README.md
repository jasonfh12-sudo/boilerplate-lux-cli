# Lux Interface Template

A minimal Next.js 15 template with Tailwind CSS v3.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## What's Included

- Next.js 15
- React 19
- Tailwind CSS v3
- TypeScript
- ESLint
